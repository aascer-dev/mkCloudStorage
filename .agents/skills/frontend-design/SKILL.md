# MKCS 前端预留规范

当前仓库只有静态演示页，没有正式 Vue/React 前端模块。本 Skill 仅在新增或维护真实前端代码时启用，不要求为后端任务创建前端工程或修改演示页。

## 产品方向

- 面向云存储高频操作：文件浏览、搜索、上传队列、分享和账户安全。界面应紧凑、可扫描、键盘可用，并明确显示上传/下载、权限和失败状态。
- 文件名、路径和服务端错误是不可信文本，渲染时防止 XSS；下载、删除、分享和权限变更应有清晰的确认与可恢复反馈。
- 上传进度、分片重试和网络断开需要真实状态，不用模拟成功代替 API 错误。

## API 对接

使用 `/api`、统一结果码和 SpringDoc 公开契约；不能在浏览器中保存服务端密钥、MinIO 凭据或 JWT 签名密钥。认证方式、跨域与回调规则遵循 `security-auth` 和 `api-contract`。
